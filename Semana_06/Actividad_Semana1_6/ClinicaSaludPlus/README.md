# ClinicaSaludPlus

Alumna: Rojas Tuesta Luz Mishel

## Descripción

Aplicación móvil para gestión de citas médicas.

## Tecnologías

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose

## Funcionalidades

- Pantalla principal
- Selección de médicos
- Reserva de cita
- Confirmación
- Historial de citas
- Perfil del usuario

├── components/
├── model/
├── navigation/
├── screens/
└── ui/
