# TecsupFit

Alumna: Rojas Tuesta Luz Mishel

## Descripción del proyecto

Aplicación de gimnasio en Jetpack Compose. Muestra clases, permite abrir el detalle y reservar. La reserva queda en Mis reservas. También tiene rutinas y el perfil del usuario. La barra inferior cambia entre inicio, reservas, rutinas y perfil.

## Tecnologías utilizadas

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose

## Cómo abrirlo

Android Studio → File → Open → `Semana_06/Actividad_Semana1_6/TecsupFit`.

Paquete: `com.rojastuesta.tecsupfit`.

## Flujo

1. Inicio: clases disponibles.
2. Detalle de la clase: recibe `classId` y confirma la reserva.
3. Confirmación y listado de reservas.
4. Rutinas y perfil, desde la barra inferior.
