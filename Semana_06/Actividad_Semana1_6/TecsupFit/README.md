# TecsupFit

Alumna: Rojas Tuesta Luz Mishel

## Descripción

Aplicación móvil para gestión de clases fitness y reservas.

## Tecnologías

- Kotlin
- Jetpack Compose
- Material 3

## Funcionalidades

- Lista de clases disponibles
- Detalle de clase
- Reserva de cupo
- Confirmación
- Rutinas
- Perfil
